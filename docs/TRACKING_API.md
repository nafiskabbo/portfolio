# Lead Tracking API

Signed, rate-limited tracking for outbound lead campaigns. Events are stored in Supabase with **minimal data** (lead UUID, event type, destination, source, hashed IP, country).

## Security model

| Layer | Behavior |
|-------|----------|
| **Lead token** | UUID v4 per lead (`t` param). Unguessable — never use sequential IDs. |
| **HMAC signature** | `s` param proves the URL was generated by your lead tool (`TRACKING_SIGNING_SECRET`). |
| **Expiry** | Optional `exp` (unix seconds). Default validity when generating: 90 days. |
| **Rate limit** | 80 requests/hour/IP; 20/hour per lead token. |
| **Auto-block** | IPs exceeding 250 tracking calls/hour are blocked for 24h. |
| **Storage** | Raw IP never stored — only SHA-256 hash with salt. |

Invalid or unsigned requests are **silently ignored** (pixel still loads, redirect still works) so attackers cannot probe valid tokens.

## URL parameters

| Param | Required | Description |
|-------|----------|-------------|
| `t` | yes | Lead UUID v4 (column in your leads CSV) |
| `d` or `to` | yes | Destination key (see table below) |
| `src` | no | Campaign source: `email`, `linkedin`, `cold_dm`, etc. |
| `exp` | recommended | Unix expiry timestamp |
| `s` | yes | HMAC signature (22 chars, base64url) |

### Destination keys (`d`)

| Key | Redirect target |
|-----|-----------------|
| `github` | https://github.com/nafiskabbo |
| `portfolio` | https://nafiskabbo.dev |
| `linkedin` | LinkedIn profile |
| `freelancer` | Freelancer profile |
| `upwork` | Upwork profile |
| `whatsapp` | WhatsApp |
| `cv` | CV PDF |
| `chat` | Portfolio chat |

## Signature algorithm

```
payload = "{t}|{d}|{src}|{exp}"
s = base64url(HMAC-SHA256(payload, TRACKING_SIGNING_SECRET)).slice(0, 22)
```

`exp` in payload is empty string when omitted.

### Node.js example (lead generation tool)

```javascript
import { createHmac, randomUUID } from 'crypto';

const SECRET = process.env.TRACKING_SIGNING_SECRET;
const SITE = 'https://nafiskabbo.dev';

function sign(payload) {
  return createHmac('sha256', SECRET).update(payload).digest('base64url').slice(0, 22);
}

function trackingUrl(path, leadToken, destination, source = 'email') {
  const exp = Math.floor(Date.now() / 1000) + 90 * 24 * 60 * 60;
  const payload = `${leadToken}|${destination}|${source}|${exp}`;
  const s = sign(payload);
  const q = new URLSearchParams({ t: leadToken, d: destination, src: source, exp: String(exp), s });
  return `${SITE}${path}?${q}`;
}

// New lead row in CSV
const leadToken = randomUUID();

const githubLink = trackingUrl('/api/t/r', leadToken, 'github', 'email');
const openPixel = trackingUrl('/api/t/pixel', leadToken, 'portfolio', 'email');
```

## Endpoints

### 1. Pixel (email open tracking)

```
GET /api/t/pixel?t=...&d=portfolio&src=email&exp=...&s=...
```

Returns a 1×1 transparent GIF. Embed in HTML email:

```html
<img src="https://nafiskabbo.dev/api/t/pixel?t=UUID&d=portfolio&src=email&exp=...&s=..." width="1" height="1" alt="" />
```

### 2. Click beacon

```
GET|POST /api/t/click?t=...&d=github&src=email&exp=...&s=...
```

Response: `{ "ok": true, "recorded": true }`

Use with `navigator.sendBeacon()` or as a hidden pixel before navigation.

### 3. Redirect (conversion tracking)

```
GET /api/t/r?t=...&d=github&src=email&exp=...&s=...
```

Logs `redirect` event, then **302** to the real URL (e.g. GitHub).

**Use this for all outbound links in emails** instead of linking directly to GitHub/LinkedIn.

Example email CTA:

```html
<a href="https://nafiskabbo.dev/api/t/r?t=UUID&d=github&src=email&exp=...&s=...">
  View my GitHub
</a>
```

## Leads CSV workflow

1. For each lead, generate `lead_token` = UUID v4 (once, store in CSV).
2. Keep email/name in CSV locally — **never** send PII to tracking APIs.
3. Build signed URLs with your lead tool using `lead_token`.
4. Query Supabase to attribute conversions:

```sql
-- Did lead X click GitHub?
select event_type, destination, source, country_code, created_at
from tracking_events
where lead_token = 'xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx'
order by created_at;
```

```sql
-- Conversion funnel for a campaign
select destination, count(*) as clicks
from tracking_events
where source = 'email' and event_type = 'redirect'
  and created_at > now() - interval '7 days'
group by destination;
```

## Chat API security (related)

`POST /api/chat` now requires either:

- Request from your portfolio origin (`Origin` / `Referer`), **or**
- Header `X-API-Key: <CHAT_API_KEY>` for external agents

Rate limit: 24 requests / 10 min / IP. Abusive IPs auto-blocked via same `blocked_ips` table.

## Supabase setup

1. Create a Supabase project.
2. Run `supabase/schema.sql` in the SQL editor.
3. Add env vars to Vercel (never commit secrets).
4. Use service role key **only** on the server.
